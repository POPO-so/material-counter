# 作品介绍

## 应用场景

《高速小型物料智能视觉计数系统》面向输送带上螺母、垫圈等小型物料的连续计数。同一物料会连续出现在多帧中，相邻物料可能短时接触或合并，因此不能直接把每帧检测数量相加作为累计数量。

项目使用 AT-OV9281 USB 摄像头、PYNQ-Z2、输送机构、照明和 HDMI 显示器。图像经前景分割与区域分析后，由跟踪器关联不同帧中的目标，在越过计数线时累计数量。实物与安装位置见[硬件页](HARDWARE.md)。

提交主线采用[队友 LJ-01 V13](V13.md)。后文的独立 RLE、JPEG 和本地密集计数优化各有自己的快照，分别用于说明原理、历史实验或优化探索，不能合并为 V13 的一次实物验收。

## 技术特色

| 设计 | 实现方式 | 对应资料 |
| --- | --- | --- |
| PS/PL 协同 | RLE 基线由 PS 解码灰度图，PL 完成 ROI、灰度偏移、阈值和可选形态学处理 | [架构](ARCHITECTURE.md) |
| 游程传输与区域分析 | PL 回传前景行游程、投影和帧状态，PS 原生模块合并 8 连通关系；普通路径不重建整帧二值图 | [RLE 运行说明](../../scripts/rle/README.md) |
| 跨帧越线计数 | 区域筛选、局部粘连候选拆分和轨迹关联配合越线滞回、已计数状态，抑制重复累加 | [计数实现](../../scripts/rle/counter.py) |
| 同帧结果展示 | 用帧身份关联图像、目标框和计数结果，再通过 HDMI 输出 | [显示集成记录](../../scripts/standalone/DEPLOYMENT.md) |
| JPEG 硬解探索 | 独立候选将压缩 JPEG 送入 PL，贯通解码、RLE/FRG 与输出监视器 | [候选包与板测证据](../../data/results/jpeg-pl-board-20261102/README.md) |

这些特色描述本项目的实现与工程取舍，不作“行业首创”声明。平均回传大小、局部算法对照和帧处理成功也不能替代端到端加速比或实物准确率。

## 面向送料问题的设计取舍

| 实际问题 | 本项目采用的方法 | 可核对依据与限制 |
| --- | --- | --- |
| 同一物料连续出现在多帧，按帧数量累加会重计 | 跨帧关联、越线滞回与已计数标志 | 检测与计数分别组织；实际漏计、重复仍须逐件真值核对 |
| 相邻物料在运动轴上的投影重叠，单一投影段可能丢失二维关系 | PL 回传游程，PS 以 8 连通规则合并区域 | 保留前景拓扑；严重粘连和完全遮挡仍有可观测性边界 |
| 传回整幅 640×400 Binary8 掩膜会产生 256,000 B 像素负载 | 正常路径传游程、投影和状态，按需重建局部掩膜 | 历史 RLE 样本回传 4,088–4,176 B/帧；这是该输入的字节数，不是端到端加速倍数 |
| 密集粘连引发重复拆分和 PS 尾部延迟 | 有界拆分准入、精确几何复用、失败与延后诊断 | [本地优化记录](../../data/results/dense-count-20261104/README.md)；没有据此认定已进入队友 V13 板端包 |
| 画面、目标框和累计数可能来自不同处理帧 | 用帧身份绑定发布，显示端重复完整帧 | 处理 FPS 与 HDMI 扫描刷新率分别统计，不能混为同一性能指标 |

本项目的应用价值在于让连续送料的计数结果可以核对、故障可以定位，并在 PYNQ-Z2 上组合像素前端和跨帧分析。它不以基础阈值、连通分析或跟踪算法本身作为团队原创算法声明。

## 已有局部优化对照

2026-11-04 的同输入主机 CPU A/B 记录以源码 `5438e0e1` 为基线：两个真实静态裁剪的完整拆分 P50 分别由 3.353/3.452 ms 降至 2.409/2.531 ms；16 孔压力样本由 9.984 ms 降至 5.205 ms。对应掩膜在这三个固定输入中保持一致。125 帧合成序列中的 100 个有身份物料逐件匹配为 100 个事件。

这些数据只证明记录条件下的局部 CPU 与合成回归效果，不是 V13 实物性能或准确率。组合回归为 870 passed、1 skipped、3 个已复现的基线失败；定向集为 125 passed，不能写成全仓回归全绿。完整环境、原始 JSON 和失败名称见[优化记录](../../data/results/dense-count-20261104/README.md)。

## 工作范围与状态

目标应用以单条主输送带保持物料单向运动，机械与照明用于维持视觉可观测条件，不承诺物料严格等间距。严重堆叠、完全遮挡和任意方向运动不属于可直接外推的能力，正式边界见[项目范围](../00_scope.md)。

当前资料以队友 V13 为提交主线，另保留 RLE 独立链路、V12 显示集成、JPEG v8 候选及后续合并源码。它们各有工件与测试边界；合并源码的存在不证明新位流已构建或通过板测。完整物料矩阵和长期可靠性仍须对应实物证据；纯视觉计数主线不以历史编码器候选作为已实现能力或新增必做项。

“高速”属于作品目标。当前已记录的 RLE 300 帧实验为约 20.57 FPS，JPEG 候选 120 帧实验为约 11.31 FPS，两者输入和验证开销不同。精确口径见[结果页](RESULTS.md)。
