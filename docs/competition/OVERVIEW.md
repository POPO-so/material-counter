# 作品介绍

## 应用场景

《高速小型物料智能视觉计数系统》面向输送带上螺母、垫圈等小型物料的连续计数。同一物料会连续出现在多帧中，相邻物料可能短时接触或合并，因此不能直接把每帧检测数量相加作为累计数量。

项目使用 AT-OV9281 USB 摄像头、PYNQ-Z2、输送机构、照明和 HDMI 显示器。图像经前景分割与区域分析后，由跟踪器关联不同帧中的目标，在越过计数线时累计数量。实物与安装位置见[硬件页](HARDWARE.md)。

## 技术特色

| 设计 | 实现方式 | 对应资料 |
| --- | --- | --- |
| PS/PL 协同 | RLE 基线由 PS 解码灰度图，PL 完成 ROI、灰度偏移、阈值和可选形态学处理 | [架构](ARCHITECTURE.md) |
| 游程传输与区域分析 | PL 回传前景行游程、投影和帧状态，PS 原生模块合并 8 连通关系；普通路径不重建整帧二值图 | [RLE 运行说明](../../scripts/rle/README.md) |
| 跨帧越线计数 | 区域筛选、局部粘连候选拆分和轨迹关联配合越线滞回、已计数状态，抑制重复累加 | [计数实现](../../scripts/rle/counter.py) |
| 同帧结果展示 | 用帧身份关联图像、目标框和计数结果，再通过 HDMI 输出 | [显示集成记录](../../scripts/standalone/DEPLOYMENT.md) |
| JPEG 硬解探索 | 独立候选将压缩 JPEG 送入 PL，贯通解码、RLE/FRG 与输出监视器 | [候选包与板测证据](../../data/results/jpeg-pl-board-20261102/README.md) |

这些特色描述本项目的实现与工程取舍，不作“行业首创”声明。平均回传大小、局部算法对照和帧处理成功也不能替代端到端加速比或实物准确率。

## 工作范围与状态

目标应用以单条主输送带保持物料单向运动，机械与照明用于维持视觉可观测条件，不承诺物料严格等间距。严重堆叠、完全遮挡和任意方向运动不属于可直接外推的能力，正式边界见[项目范围](../00_scope.md)。

当前资料包含 RLE 独立链路、V12 显示集成、JPEG v8 候选及后续合并源码。它们各有工件与测试边界；合并源码的存在不证明新位流已构建或通过板测。编码器带速、完整物料矩阵和长期可靠性仍须对应实物证据。

“高速”属于作品目标。当前已记录的 RLE 300 帧实验为约 20.57 FPS，JPEG 候选 120 帧实验为约 11.31 FPS，两者输入和验证开销不同。精确口径见[结果页](RESULTS.md)。
