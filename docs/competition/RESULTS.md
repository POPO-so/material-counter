## 版本与证据口径

本页于 2026-11-04 基于 GitHub 默认分支 `LJ-01` 的 `7c8684a9` 整理。此前记录的冻结源码 `5438e0e1`、RLE 独立链路、V12 显示集成和 JPEG v8 包是不同快照，测试结果应分别绑定源码、工件与输入条件。

以下为已有报告摘要，本次文档发布不重新进行板测，也不修改历史记录的状态。源码合并不等于重新综合、生成新 BIT/HWH 或完成硬件验收。

RLE、JPEG 和带 HDMI 的集成配置开销不同，不将它们的 FPS 横向解释为优化加速比。相机帧率、处理 FPS、显示更新、HDMI 扫描刷新率和浏览器显示 FPS 也不是同一个指标。

本次文档发布另从独立检出执行了[离线样例](../DEVELOPMENT.md#离线运行)：`OFFLINE_VERIFIED`，12/12 帧通过像素重建比对，合成移动目标累计数为 1，无效帧为 0，`count_accuracy` 保持 `NOT_MEASURED`。这是主机合成验证，未访问开发板；摘要见[发布检查记录](../verification/github-docs-20261104.json)。
