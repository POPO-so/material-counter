- count_accuracy=NOT_MEASURED 仍为当前口径；板端启动、空场帧、合成越线及历史演示截图都不能替代真实物料真值。

- 正式提交材料和开放发布材料属于不同清单；涉及大文件、签字或未核授权内容时按 [上传核对](UPLOAD.md) 与[第三方记录](THIRD_PARTY.md)处理。
