## 1. 数量、面积和坐标预算

统计来自完整21条H3、487张实际PNG，Binary阈值128，无GT辅助检测。
`data/results/wo0011-ablation-final-20261013/summary.json` 保存参数/输入哈希/feature_budget。

| 项 | H3实测 | 建议与限制 |
|---|---:|---|
| 同帧物理对象 | 20（GT仅用于需求审计） | 不能用合并后的1条记录反推容量只需1 |
| 同帧未过滤连通域 / 正常有效特征 | 最大20 / 20 | 真实噪点/供料密度未测，20不是生产上限 |
| 活跃轨迹 | 基线最大20；膨胀最大30 | PS容量需计入失踪旧ID及噪声，不能等同记录数 |
| 分离矩形bbox | 8×14 | 仅当前合成尺度，不是实物先验或拆分周期 |
| 分离区域面积 | 112 | 一次腐蚀规则下矩形变6×12=72；薄环可完全消失 |
| 原始连通域面积 | 112～2240 | 面积不是bbox面积；孔填充会改变物理前景面积定义 |
| 最大合并bbox | 160×14 | 宽度>24仅是参考异常门限，不能把宽区域自动切成N目标 |
| 最大全帧前景数 | 2240 | 320×240理论上限76800，应保留全帧32位统计 |
| 封闭孔填充改变像素 | 0 | H3没有孔，真实垫圈适用性尚无证据 |

候选首版可评估64条记录的参数化容量，覆盖已测20并留有余量；**64为Hypothesis，不是冻结值**。
接口B的8位seg_count最多表示255，容量超过255不能直接沿用该字段。
达到容量上限时设置既有帧overflow标志并按原子性合同丢弃整帧，禁止静默截断后继续累计。
增加真实高密度/噪点/多行样本后，再确认上限和FIFO/DMA批次预算。
若暂以16字节对齐记录、16字节帧尾做估算，64条约1040B/帧、30fps约31.2KB/s；
这是未冻结的内存布局算例，不是已实现DMA传输或PL资源占用。

参考min_area16可以作为实验默认值保留，不升级为实物最小面积规范。
H3将门限提高到128会滤掉所有112面积的分离目标，使事件TP从19降为0；降低到1未提升。
真实最小投影面积必须在固定相机/距离/光照/阈值下标定，并同时检查孔、薄壁、触边和Morph模式。

接口B面积16位上限65535；320×240全连通区域可能超出，不能截断回绕。
需在ADR中明确拒收/饱和及对应状态合同；当前参考使用Python整数不等于硬件已支持。
320×240的x/y坐标可由既有10/8位覆盖；stretch640×480的row和centroid_y超过8位范围，需受控接口决策。

## 2. 质心、标志与异常记录

输出必须保留包含端点的bbox、前景面积、质心和Route二维有效标志。
已有bit0疑似合并、bit1触边、bit2二维字段的含义不变；不擅自分配新增位。
ROI坐标是全帧还是局部、质心计算/取整规则、整数除法误差均须正式定义。

WO-0010软件质心带小数，接口B仅给出10/8位和列/行含义，未明确小数缩放与取整细则。
本轮仅将向下截断为整数作为一种候选实现试验，并非认定该编码已经冻结：
仍输出19事件，其中14个发生时刻晚于原first-visible-qualified-frame；严格协议仅TP5/FN26。
这14个是**时机不符**，不是14个新物体或随机重复；总数相等无法验证接口等价。
建议做PL黄金对照时明确量化策略并评估时机误差，未经审批不变更既有计数线/迟滞或给评分放宽窗口。
不能把一个矩形的bbox中点恢复方法推广为任意带孔/不规则物体的真实质心。

需覆盖：没有目标、1/20/容量上限/超上限、面积溢出、边界截断、孔与薄环、孤立噪点、
细桥连接、无缝同色接触/重叠、投影重叠但2D分离、行尾/帧尾、reset半帧、反压、掉帧和配置切换。
H3膨胀会出现不超过24宽度的局部合并，当前宽度标志无法识别全部异常；
不能把“没有merge flag”当作“此Region必为单物体”。异常仍需工作包线/PS诊断/独立证据。

完整帧记录与帧尾元数据必须绑定同一frame_id；seg_count、收到的记录数及长度不一致整帧拒收。
缺帧保留ID间隙，禁止把半帧/混帧提交跟踪；时间戳、溢出、reset/epoch与缓冲所有权按待确认合同处理。

## 3. Route/G1决策材料还缺什么

已具备：二维参考、逐对象事件评分、完整H3消融、12例失败证据、投影重叠诊断、临时帧通路提案。
仍缺：独立Route A完整计数结果与共同有事件窗口、真实录播至少5条的人工真值、
机械工作包线测量、候选PL资源/时序/吞吐证据以及正式Route ADR与三人确认。
无缝接触的原H3像素域缺少分割边界，不应以强行按固定物体宽度切片获得“31/31”证明G1通过。

最小候选仍为分离/可观测目标的轻量PL特征输出，PS保持跨帧关联和计数，
临时Binary帧→PS用于参考与兜底。完整PL CCL、通用遮挡或新的硬件Morph链未获批准。
建议下一步投入真实垫圈/螺母图像与可测的送料间距，先确定像素可分离包线，
然后依据共享事件协议比较Route A/B，不能用本轮无提升的H3实验自动冻结Route。
