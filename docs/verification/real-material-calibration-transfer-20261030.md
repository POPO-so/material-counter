# 实料标定知识移植与 640×400 重新标定流程（2026-10-30）

本文件把 `main` 分支在 320×240 上积累的实料标定知识带入 LJ-01 架构，并规定在
640×400 原生分辨率下重新标定的步骤。**本文件不含可直接使用的 640×400 参数。**

## 1. 继承的知识（历史证据，仅 320×240 有效）

来源：[optimization_ledger.md](../benchmarks/optimization_ledger.md) 阶段三、B-2 attempt-03。

| 项 | 320×240 取值 | 证据等级 |
|---|---|---|
| 固定 PL 阈值 | 128 | 历史板测（TX 私有图像 +27 补偿后等价） |
| PS 补偿偏移 | +27（饱和） | 历史板测 |
| 源图 ROI（PS 侧） | `[20, 380)` | 历史离线标定 |
| 输出 ROI（计数用） | `[30, 210)` | 历史板测 |
| 源图连通域净面积下限 | 60 | 历史离线标定 |
| 输出区最小面积 | 15（快速 `output-roi` 模式） | 历史板测 |
| 连通域子件下限 | 60（B-2 改为 48） | 历史板测 |
| 粘连孔面积下限 / 封顶 | 16 / 16 | 历史板测 |
| 有效狭颈比例 | 0.25–0.75 | 历史板测 |
| 有限递归拆分面积下界 | 80 | 历史离线 |
| 单件面积提示（暂定） | 80 = M6 平垫圈、111 = M6 螺母、150 = M8 螺母 | **暂定假设**，未做逐件真值标定 |

已知失败形态（同样只对 320×240 成立）：

- 3 个粘连 M6 螺母反复只计 1 件；2 个沿输送方向串接的 M6 螺母仅少数轮次成功拆分。
- 动态轮曾出现物理 54 件 / 仪表 46 件（测试段 44 件，约少 10 件）。
- 15 件静止物料拆分分组 3/2、前景面积守恒 1692 px（用于校验拆分不丢面积）。

## 2. 为什么这些数值不能直接用在 640×400

- 面积与分辨率成平方关系：320×240 → 640×400 的像素数是 3.333 倍，同一物料在
  640×400 上的面积约为 320×240 的 **3.33 倍**；`min_area` / `max_area` /
  `single_intact_area` 沿用旧值会把正常物料判成超限或把噪点判成物料。
- 距离量（`max_step`、`max_x_step`、`max_lateral_step`、`component_cluster_dy`）
  随像素尺寸线性变化，横向约 2.0 倍、纵向约 1.67 倍，不能用一个系数统一换算。
- ROI 边界、计数线位置是绝对坐标，必须按相机视场重新确定。
- 亮度偏移与阈值是光学/曝光相关量，与新采集链（直接解 MJPEG 为 Gray8，不缩放）
  无关地重新成立，必须重测。

`scripts/rle/README.md` 已明确：坐标必须已经换算并标定到 640×400，不会自动套用旧
320×240 面积或距离。本流程遵守该约束。

## 3. 重新标定流程（640×400）

前置条件：灯光、镜头、相机高度、带速与实际生产工况一致，并记录到标定记录中。

1. **空带基线**：无物料采集 ≥300 帧，确认计数为 0、`rejected_components` 为空或全部
   可解释为噪点；记录灰度直方图与前景像素数的分布上界。
2. **阈值与偏移**：对目标物料分别采集亮/暗两类样本，扫描阈值，取使「物料前景面积
   稳定、背景不误检」的平台中点；阈值与偏移写入 PL 配置并由硬件时间戳帧验证锁存
   生效。当前 RLE 通路的比较关系是 `>=`，偏移默认为 0。
3. **单件面积标定**：对 M6 平垫圈、M6 螺母、M8 螺母各采集 ≥30 件独立样本（不接触），
   统计面积均值/中位数/分位数，得到 640×400 下的面积分档，用于 `min_area`、
   `max_area`、`single_intact_area`、`max_split_area`。
4. **几何门限**：由单件包围框统计确定 `max_bbox_width` / `max_bbox_height`；由相邻
   物料最小间距与帧间位移统计确定 `max_step`、`max_x_step`、`max_lateral_step`、
   `component_cluster_dx/dy`。
5. **粘连拆分**：用已知件数的粘连组（3 件、4 件、串接、并排、部分重叠）逐组验证
   `split_min_hole_area`、`split_hole_area_cap`、`split_recursive_item_area`、
   `min_split_child_area`；以「拆分后面积守恒」与「组内件数正确」为双门禁。
6. **越线计数**：用人工逐件真值（记录每件越线的帧号）测漏计/误计/重复计数，至少
   200 件连续过料，重复 3 轮；同时记录 `diagnostics` 中的 `rejected_components`、
   `lost_tracks`、`ambiguous_associations` 与 `association_candidates` 以定位失败点。
7. **写入与复核**：标定结果以 JSON 配置 + 标定记录（含 boot ID、位流哈希、采集帧数、
   真值件数）形式提交，禁止把标定结果写成代码默认值绕过评审。

## 4. 与 A/B 基准的关系

已完成的 A/B 基准（`data/results/debug-counting-ab-benchmark-20261029-01/`）只覆盖
320×240 的三条特征表示通道，三条 lane 使用同一个 tracker，且相机序列
`ground_truth_status = NOT_RECORDED`。它**不能**用于 640×400 的标定或验收。
重新标定必须使用第 3 节流程产生的新数据与人工真值。

## 5. 未验证项（截至本文件）

- 640×400 下没有任何 M6/M8 面积分档实测值。
- RLE 通路没有任何人工真值的计数准确率结果。
- 上文「单件面积提示」与失败形态均为 320×240 历史记录，迁移后需重新确认。
