静态审计：

- 采集循环内仍无 `np.savez/open/memmap/flush/fsync`；
- RAM 模式只分配一份 `source` 数组；每帧的 `gray` 是 OpenCV 返回的临时缓冲（256 KB），
  不生成 320×240 预览数组；保存时 `source[:captured]` 是视图，不复制；
- 诊断数组为 4 × frames × float32（450 帧 7.2 KB）。

## 2. 450 帧内存预算

| 项 | 值 |
|---|---|
| 源帧 | 450 × 400 × 640 = **115 200 000 B（109.9 MiB）** |
| 时间戳 + read_ms | ≈ 9 KB |
| 运行时余量 | 128 MiB |
| 估算峰值 | (115.2 MB + 128 MiB) × 1.25 = **311.8 MB（304 487 KiB ≈ 297.4 MiB）** |
| 板端准入 | `MemAvailable ≥ 304 487 KiB`，且按要求 ≥ 350 MiB |
| 磁盘准入 | 预计字节 ×2 + 256 MiB ≈ **498.9 MB** |
