    Implements WO-0001.
    
    - backbone: 15 sequences covering the full 3 speeds x 3 spacings matrix
      plus noise and dropped-frame variants
    - special: 6 sequences (single-column, small spacing, lateral offset,
      x-projection-overlap/non-contact, speed variation, short pause)
    - resolution unified to 320x240 Gray8; width/height stay spec-driven
    - spec gains a parameterised grid object ({count, spacing, stagger}) so the
      matrix stays compact; ids remain explicit
    - Pillow kept and confined to PNG I/O; no algorithm use
    - .gitignore: data/synthetic/**/frames/ so generated frames never enter git
    - tests: 7 acceptance tests incl. the R2 falsification sample asserted over
      every valid frame, byte-identical determinism, and a Pillow-scope guard
    - removed docs/superpowers/ (superseded planning artifact); its durable
      scope statement moved into the synth module docstring
    
    No detection, segmentation, tracking, counting or Route A/B/Hybrid code.
