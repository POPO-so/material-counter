## 2. 输入、接口与计数合同

实际遍历21个H3条件：504个GT帧、10,080条对象标注、487张原始PNG、17个整帧缺失。
PNG缺失与配置/GT一致。H3的 `visible=false` 表示整帧丢失；个体失踪/重现由补充测试覆盖。
冻结H3是矩形目标，尚不能代表真实垫圈/螺母、光照和运动模糊。

参考参数：Gray>=128为FF前景，8连通，min_area16，Morph旁路，宽度>24标为疑似合并；
计数线x=160，+X方向，迟滞h=2，连续两次观察确认，允许两个缺失帧，
每帧最大位移门限6、纵向门限8。参数是可复现假设，未经实物校准或正式冻结。
Morph备选腐蚀/膨胀采用3×3零背景边界；区域测试与既有黄金模型对照。

Region使用包含端点的 `(x_min,x_max,row_min,row_max)`、面积、质心和标志。
面积保留Python整数，90000像素用例通过；当前没有接口B的16位面积打包或溢出约定。
GT的object_id、visible、速度不进入关联器。图像推理后才做外部GT匹配；GT几何诊断先剥离身份并打乱输入顺序。
几何字段含义参考接口B，但不代表已实现其序列化、时间戳或硬件传输。

轨迹观察到x<158才armed，确认后观察到x>162发一次计数。缺帧只预测关联，不预测计数。
线后新生目标不会补计；重复/倒序帧号拒收；完全重复特征去重且记录诊断。
方向=-1有对称测试。疑似合并只暂停接收该特征，不声称完成拆分或复杂遮挡恢复。

独立真值有35次物理中心线穿越，其中31次完成严格迟滞退出，4次到序列终点仍待定。
此前初审25/22/3已纠正，原GT和计数规则未改。主指标以31个可确认事件为分母，
同时保留35次中心线真值，不能用迟滞分母掩盖待定事件。
特征匹配IoU>=0.5；计数TP要求同一GT对象且事件发生在完成迟滞退出后的首个可见帧，
总数相等、错误身份或错时事件不能冒充TP。该评分未使用额外宽松延迟窗口。

## 3. 实测结果

| 通路 | 可确认真值 | TP / FN | 重复 / 无对应事件 | 精确率 / 召回率 |
|---|---:|---:|---:|---:|
| 原PNG→区域→跟踪→计数 | 31 | 19 / 12 | 0 / 0 | 100% / 61.29% |
| 剥离身份的GT几何→跟踪（诊断） | 31 | 31 / 0 | 0 / 0 | 100% / 100% |

图像总数19，相对中心线真值35少16，相对可确认真值31少12。
特征TP6940、FN2800、FP140，正常可见对象总数9740；140次疑似合并观察被拒收。
已匹配观察中的ID switch为0，这不能证明失踪、合并期间的身份完全恢复。
15个分离/非接触条件的图像可确认事件19/19；所有21条件均保留在主评分中。

主运行PC平均每GT帧1.445ms，重复运行1.422ms；GT几何诊断分别0.463ms、0.454ms。
这些耗时包含PNG读取、参考推理及GT评分，且两次最终评估并行运行；不是独立PS算法基准、
不是ARM吞吐，更不能替代摄像头连续输入、DMA或板端实时性测量。
排除耗时字段后的完整轨迹摘要两次一致：
`8e0c20f1755549abb61e824ab8265d255c280110018089ba076b325f5e521dc1`。

## 5. 失败场景与能力边界

| H3条件 | 可确认真值 | 图像计数 | 漏计 |
|---|---:|---:|---:|
| backbone_fast_small_01 | 4 | 0 | 4 |
| backbone_nominal_small_01 | 3 | 0 | 3 |
| backbone_nominal_small_02 | 3 | 0 | 3 |
| backbone_slow_small_01 | 1 | 0 | 1 |
| backbone_slow_small_02 | 1 | 0 | 1 |

上述五条件贡献12次事件漏计。六个接触/重叠序列共140张PNG导致2800个独立特征漏检、140个合并特征；
第六个small_spacing在默认线没有越线真值，总数0相等不能说明分割正常。
H3矩形宽8，同排间距8会接触、6会重叠；单纯连通域不能恢复原物体身份。
本轮没有使用GT切割、按真值调参或删掉困难条件。

人工补充明确展示：长期消失期间跨越计数线会漏计；超出单向/反向门限的大幅逆向运动，
旧ID失效后在线前重生并再次穿越可能重复计数（专门测试得到2次）。
最近邻不保证复杂交叉/长遮挡身份，局部宽度门限也不是通用粘连检测器。
有限离线审计保留finished轨迹；生产部署需限定历史长度、重置epoch和计数生命周期。
尚未验证PYNQ环境依赖、真实编码器、真实目标准确率或ARM运行耗时。

## 6. G1补证与候选架构

`projection_overlap_noncontact`的24帧均为20个独立2D区域，但非零列投影只有1段。
默认line160在该序列有0事件，不能用计数0相等验证Route区分能力。
另列明line128诊断：该条件有4个可确认事件，图像参考命中4；完整21条件为TP28/FN16，
精确率100%、召回率63.64%。补充运行在 `wo0010-line128-20261013`；未替换主line160结果。
主结果目录的 `g1-projection-diagnostic.json` 保存逐帧20/1证据。

该补证说明投影合并风险，**不是完整Route A实现或A/B端到端比较，不宣称G1已通过或Route已冻结**。
需补Route A独立参考和有事件的共同测试窗口，并结合实际垫圈/螺母序列、吞吐/资源证据形成ADR决策。

建议继续使用已原则批准的临时二值帧→PS参考兜底；正式目标仍为PL区域特征→PS跟踪计数。
下一候选最小PL方案可限定为分离目标的区域/特征输出，显式记录容量/溢出/粘连状态，
用本参考Region与计数器作为对照，不立即承诺完整CCL或复杂拆分。
此候选需要Route/ADR确认后才定义硬件边界；未据此改变任何正式接口。
