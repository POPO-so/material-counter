# ADR-0005：脱机灰度 HDMI 显示候选增量

状态：**Proposed / 已获实施授权，待正式签核及阶段实测**。

用户要求按根目录《计划.md》实施 PYNQ-Z2 脱机运行与灰度分屏。候选实现复用 PYNQ 3.1.1 视频驱动和官方 v3.1 视频 IP 源码，PS 保持单通道，HDMI 使用独立时钟域和 HP2。详细候选地址、输出帧身份和快照 ABI 见 [设计](../superpowers/specs/2026-10-29-standalone-display.md)。

先通过 G1 和 G1.5，再投入 RLE 完整集成。8-bit 输出出现问题时保留诊断并定位，不自动切换 24/32-bit 或引入 PS 三通道合成。显示完成依据为输出端完整新帧身份；提交或重复扫描不能代替有效显示。无法证明 DMA 停止时禁止释放其缓冲。

此记录不更改正式 Route、视频输入路线或原有接口冻结状态，也不构成脱机系统完成或物料准确率证据。实施状态和验收证据由根目录《计划.md》追踪。
