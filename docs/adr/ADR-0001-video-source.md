## 背景

PYNQ-Z2（Zynq-7020）上**没有 MIPI CSI 座子**。项目的核心叙事是"PL 处理像素流"，因此视频源通路是**致命级风险（R1）**。

已确认：板子**具备 HDMI IN / OUT**（AMD 2026 官方指南）。

**但"有 HDMI IN 口" ≠ "能用它接我们的流水线"。** 待核实的是接入条件，不是端口存在性。

## 待决策项（C2 四项 + C3）

| # | 待核实 | 状态 | 结论 |
|---|---|---|---|
| C2-① | HDMI IN 在当前 PYNQ / Vivado 环境中的实际接入方式 | ☐ 未做 | |
| C2-② | 所需 IP / Overlay / video pipeline | ☐ 未做 | |
| C2-③ | 是否方便接入**我们自己的 AXI4-Stream PL 图像处理流水线** | ☐ 未做 | |
| C2-④ | 是否适合作为 **Competition Version 的最终真实视频输入** | ☐ 未做 | |
| C3 | 可用扩展引脚总数与电平；DVP 约 15 根信号线能否放下 | ☐ 未做 | |

## 四条候选路线（**并列，未冻结**）

| 路线 | 优势 | 风险 |
|---|---|---|
| **HDMI IN** | 板载，无需外部引脚；标准视频源 | 接入方式 / IP 依赖未知；延迟与帧率控制待确认 |
| **DVP / Pmod 摄像头** | PL 直连，时序可控；纯 PL 采集 | 需约 15 根信号线；引脚预算未确认（C3） |
| **USB 摄像头** | 最快跑通；PS 侧 V4L2 | 走 PS → DMA，非纯 PL 采集；独占问题 |
| **文件回放** | 完全可控，无硬件依赖 | FPGA 叙事变弱（"回放流的实时处理"）；诚实退路 |
