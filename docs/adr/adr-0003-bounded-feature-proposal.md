# ADR-0003 · 有界PL特征提取技术草案

状态：**Proposed / Technical draft，未批准、未实施，不是Route冻结ADR。**
日期：2026-10-13。按用户WO-0012要求准备技术内容；正式决策由人填写和三人评审。
决策者、签字、批准日期均尚无记录。不得把本草案存在当作MASTER_PLAN附-6的人类架构决策已完成。

## 背景与问题

WO-0011已单独本地提交a67fe87，完整H3图像TP19/FN12，全部漏计来自无缝同色接触。
形态学旁路是当前参考基线；G1的R1未有达标证据，R2没有完整Route比较/正式冻结。
正式目标仍为PL特征、PS跟踪计数，临时二值帧→PS用途获原则批准，但具体DMA和生产接入未批准。
需要明确一个低复杂度硬件候选，供评审与后续板级验证排期，不能立即扩大到通用CCL。

## 推荐候选（由人决定是否采纳）

1. 首版320×240，Binary8/旁路，单向物料，PS承担关联与越线。
2. 行程编码与邻行8连接，固定统计槽；当前run无前驱出生，只有一个前驱ID则沿用。
   同ID可分叉并汇合以覆盖部分孔；不同ID汇合整帧拒收，不引入union-find。
3. 示范输入密度先按H3的20个同时对象规划，物理包线仍须真实H5验证；
   ACTIVE_CAP=32、RECORD_CAP=32为nextpow2(20)，不把20当所有真实输入的已测上限。
4. 两行run缓存物理各64槽；建议运行row-run限值40，来自独立20个单孔目标每行40run的算例。
   64是nextpow2(40)的存储，不是承诺64物体或64run持续30fps。
5. 面积16～65535、bbox包含端点、整数矩最近值半值向上；溢出/不支持形状/坏帧原子拒收并报告。
6. 普通AXI DMA的首版隔离文件回放POC，特征和Binary帧人工选模式，不能假定实时自动兜底已存在。
7. 16B记录+16B帧尾，小端AXIS32。epoch16与错误位是**拟新增**合同，须接口PR+三人确认+ADR。

细节见 `docs/wo-0012-feature-transport-draft.md` 和 `docs/wo-0012-g1-decision-package.md`。

## 被比较的替代方案

| 方案 | 处理能力与代价 | 当前建议 |
|---|---|---|
| 完整PL CCL/特征 | 可合并等价标签和复杂拓扑，但仍不能凭像素恢复无缝同色物体身份；状态与验证成本大 | 不选择，超当前Scope/工期边界；本轮无生产实现 |
| 有界run提取 | 固定容量/无跨根合并，精确区域矩；多根后汇合的单物体也会拒收 | 推荐技术补证候选，先核验拒收率与真实形状 |
| PS区域兜底 | OpenCV完整二维参考已可运行；要传全Binary帧，PS板端耗时/缓存未知 | 保留参考/兜底，不能默默代替正式PL职责 |

这三种是实现范围，不等同项目Route A/B/Hybrid。R2仍需独立路线比较。

## 收益、限制与否决条件

收益：不保存整帧标签图；容量/矩位宽/行处理有固定边界；保留2D信息；与PC黄金逐记录比较。
限制：不接受先多根出生后汇合的U形/部分不规则物体，未验证真实旋转螺母/垫圈的拒收率。
无缝同色接触仍一块Region；宽度标志是启发式，不能保证查出所有真实粘连。
整数误差≤0.5仍可能改变越线时机；H3无新增计数损失不证明真实序列普遍等价。
源不可暂停时需要按突发/消隐与实际服务曲线预算FIFO或DDR，平均30fps不足以确定大小。

若真实工作包线中的正常单物体频繁触发多根拒收、容量不足或量化导致R1不达标，
暂停此候选并提交新的技术决策；不能悄悄加通用标号合并或扩大正式Scope。
资源5～7个BRAM36等价块仅为映射假设；无新综合、时序收敛、板端FPS或完整DMA证据。
