# B 版 PS 仪表盘布局调整设计

日期：2026-11-03

## 目标

调整 PS 端仪表盘信息层级，避免预览周围的文字互相遮挡，让目标数量、本次累计计数和按键说明更容易读取。保留 1280×720 Gray8 输出；将二值预览画面按最终布局设为 512×320，不裁切图像内容，也不改 PL、bitstream 或硬件接口。

## 依据与取舍

- 当前 `DashboardComposer` 使用 Pillow 灰度画布和 `uint8` 帧缓冲；HDMI 以 `VideoMode(1280, 720, 8, 60)` 和 `PIXEL_GRAY` 配置。视频泵把二维 Gray8 预览帧复制到 HDMI 帧缓冲。
- 当前源码实际 viewport 为 `DashboardComposer.VIEW=(398, 154, 460, 288)`，临时缩放缓冲为 460×288。最终布局将其改为 `(384, 146, 512, 320)`，PS 预览缩放像素数增加约 24%；输入/计数处理和 PL 数据不变。
- RGB24 每像素需要 3 字节；1280×720 单帧由 921,600 字节增至 2,764,800 字节。逐帧读写的数据量也约为 3 倍，实际 CPU 时间取决于内存带宽和绘制路径，不应直接等同于 3 倍。
- 当前 HDMI/PL 路径按 Gray8 运行。RGB 输出至少需要将 PS 画布和 HDMI 帧缓冲改为多通道，并核对现有输出硬件是否支持；如不支持则需改 PL 并重新构建。因此本次保持 Gray8，RGB 作为单独评估项，不纳入本次变更。

## 布局方案

1. 二值预览保持 512×320，左上位置保持 `x=384, y=146`，中心为 `x=640`，上下位置不变；加 2 px 灰色边框。左侧信息栏为 `x=38, width=342`，右侧信息栏为 `x=900, width=342`，预览与两侧栏之间各留 4 px 间隙。
2. 将底部红框空位按约 1.12 倍比例扩展信息板块高度，使两侧板块下沿到 `y=466`：左侧画面规则 / 曝光 / 处理性能高度分别为 104 / 55 / 148 px；右侧累计计数 / 按钮功能高度为 213 / 102 px。保留预览 y 坐标和主面板边界。
3. 顶部四个指标改为宽 296 px，x 坐标为 24、336、648、960，间距 16 px；最右侧边缘为 `x=1256`，与仪表盘主面板和预览区域外框对齐。每个卡片中的标题和值都在卡片内水平居中，作为一组垂直居中显示。
4. 顶部第一个指标与右侧“检测结果”互换：顶部改为“目标数量”，显示现有检测目标数值，不在该指标内显示跟踪 ID；不新增计数逻辑。
5. 右侧较大的信息区显示“本次累计计数”；标题居中，数值文字框的中心精确对齐整个计数卡片的几何中心（水平和垂直）。会话说明保留在数值下方居中显示。
6. 曝光控制保留当前曝光值，移除“范围 / 步进”参数行。
7. 删除“预览链路”卡片。原“检测结果”及“预览链路”两块空间合并给“本次累计计数”卡片；卡片只承载本次累计计数信息。
8. 将“运行状态”区域改为“按钮功能”卡片，放在二值预览右侧下方。将 BTN0–BTN3 与 SW0 的全部现有按键说明集中放入这张卡片；清除左侧下方重复的按键说明。
9. 右上角状态白点按 1 秒周期闪烁，亮灭各约 0.5 秒；“RUNNING”字号提高到与“NUT VISION COUNTER”相同的 28 px，文字右边缘对齐 `x=1256`。白点与文字垂直居中，点的右缘与文字左缘间隔约 15 px。仅更新指示点的小区域，避免为闪烁重绘整张仪表盘。
10. 处理性能区的 PL / RLE 标签和汇总值保持一行显示。检查并清理无用途的末尾空白单元格；不新增空列。当前源码绘制标签及汇总文本，没有单独的末尾单元格。
11. 左右侧栏中各卡片标题及信息行均水平居中；多行内容行距统一为 20 px，信息行组在卡片内容区上下居中。标签和值合并成一行居中显示，不再采用左标签、右值的分列布局。

## 保持不变

- 预览仍为完整的 512×320 二值图，不做裁切、缩放或图像数据处理变更。
- 画布仍为 1280×720 Gray8；不修改 HDMI 输出格式、PL、bitstream、DMA/VDMA、计数算法、跟踪 ID 数据或物理按钮行为。
- 本次只改变 PS 仪表盘的文字和卡片布局。

## 验收口径

- 目标数量卡片的标题和值在卡片内居中显示，不显示 ID。
- 四个顶部数据卡片中的标题和值均居中；最右卡片边缘与主面板对齐。
- 本次累计计数标题居中，数值中心与卡片几何中心重合；预览完整显示为 512×320、带边框，保持原 x/y 坐标且与左右侧栏间隙相同。
- 左右卡片标题和信息行水平居中；多行信息行距一致，行组在卡片内容区上下居中。
- 左右空位由侧栏板块按相近比例扩高填充；顶部四项数据最右边缘与主面板右边缘对齐。
- 曝光范围/步进行和预览链路卡片不再显示；BTN0–BTN3 与 SW0 的完整操作说明只在右下“按钮功能”卡片中集中显示，左侧下方不再重复。
- “RUNNING”字号与“NUT VISION COUNTER”相同且右对齐；白点与文字垂直居中、间距约 15 px，并按 1 秒周期闪烁。
- PL / RLE 汇总行无无用尾部空单元格。
- 界面缓冲仍为 1280×720 的 Gray8；不触发 PL 综合或重新配置。
