帧 37650 等设备结构图像不属于目标物料运动片段，不用于本设计的漏计证据。

## 目标和边界

- 减少视觉工作包线内短时接触、局部粘连及跨线后分离造成的漏计。
- 对每个物理物料最多计数一次；避免通过无条件放宽区域阈值制造重复计数。
- 修复范围限于现有 ARM PS 的 RLE、拆分和跟踪计数路径。
- 不修改 PL、视频路线、正式接口契约或对外计数接口；不引入新运行时依赖。
- 不承诺处理严重堆叠或完全遮挡，遵循[项目范围](../../00_scope.md)。子物料数上限由逐件标注的可观测工作包线校准并保持有界；无法可靠判断时保留诊断证据，而非静默推测数量。

## 方案比较

| 方案 | 说明 | 结论 |
|---|---|---|
| 只调面积和聚类阈值 | 放宽最大面积或关闭最终合并 | 不采用。可能把整团当成一个物料，或把单个物料的碎片重复计数。 |
| 基于环形形状拆分大区域 | 在父连通域内寻找多个孔心/环形种子，按种子拆分并校验子区域 | 采用为主路径；必须覆盖超过 1200 面积且子物料数超过 3 的候选。 |
| 跨线父子轨迹恢复 | 记录父粘连团越线；若下游出现可关联且稳定的子轨迹，只补计尚未计过的子物料 | 采用为补充路径；没有父团关联的线后新轨迹仍按现有规则抑制。 |

## 建议设计

### 1. 大区域候选拆分

对面积或外接框超限的组件，在拒绝前执行有界分析。以环孔中心、环形边缘等已有图像特征生成多个种子，再在父组件掩膜内分配像素。允许在标定上限内拆出超过 3 个子物料；面积、孔心间距、子区域连通性、掩膜覆盖和残余区域均须通过校验。不扩展为不受限的堆叠分割。

父区域分析必须有明确的最大像素数、候选种子数和临时缓存上限。拆分未达到置信条件时，保留为歧义/拒绝诊断，不把整团强行当成一个物料。单物料区域与现有最终聚类策略保持兼容。

### 2. 粘连团跨线与子轨迹关联

当大区域接近并通过计数线时，记录有限寿命的父团状态、运动方向和覆盖范围。若该父团之后分解为多个稳定子轨迹，按父团覆盖和时序关联确定哪些子物料已越线，并对尚未计数的子物料产生一次计数事件。

若子轨迹能关联到已计数的独立轨迹，不再补计；若线后轨迹无法关联到已越线父团，维持现有“线后出生不计数”规则。父团状态超过有界帧数、关联冲突或种子数不可信时，结束自动恢复并留下诊断信息。

### 3. 保持现有观测契约

保留 `raw_detections` 与最终 `detections` 的现有含义及外部接口。继续记录拒绝区域、轨迹关联和 CountEvent；必要诊断只扩展快照内部内容，并版本化其字段，不改变主计数接口或 UI 契约。

## 验收设计

实施后使用同一份固定输入离线回放，并准备一段逐件标注的 100 件视频，确保采集开关有效、运行区间无清零且每件物料有人工真值。覆盖单件、2–3 件接触、超过 3 件的短时粘连、线前合并后线后分离、线后无关新轨迹及高反差/低反差场景。

验收记录至少包括：最终计数、逐件漏计与重复计数、歧义区域数量、父子关联结果、计数延迟、单帧区域和跟踪耗时、最大临时内存。100 件标注批次目标为计数 100 且无重复事件；超出可观测工作包线的样例须显式归入歧义，不以偶然总数相等视为通过。连续回放时处理速率须不低于输入速率且队列保持有界，并报告 p50/p95 区域与跟踪耗时。通过离线验收后，再在板端测量 PS 处理开销，决定是否进入快速部署。

## 依赖与风险

- 当前快照只保存有限上下文帧，且部分触发因队列满未保存；需要完整且有真值的验证输入。
- 孔心特征受遮挡、反光和阈值影响；拆分置信度必须由真实标注数据校准，不能仅凭合成形状确定。
- 父子轨迹恢复有重复计数风险；实施时须记录每个子轨迹的父 ID、越线状态和计数状态，确保一物一事件。
- 板端最新一次启动记录未启用快照并进入 `FAIL_HOLD`，新算法验收前需先确认采集配置和相机释放状态。
