# 图像处理调试模式

## 目标与边界

在现有 WO-0016 控制看板中提供默认关闭的图像调试模式，按实际运行的处理步骤展示同一帧的处理前后画面。保留现有采集、阈值、计数和预览行为，不改变硬件协议或计数算法。

## 交互与数据

- 一键开启或关闭；关闭时停止调试专用的中间图像采集、绘制、编码和传输。页面显示启用状态及连接、等待和停用状态。
- 启用后限频生成同一帧的调试快照，包含帧号、来源和实际配置；每一步以处理前、处理后并列呈现。
- 展示相机灰度图到映射后 Gray8、Gray8 到 Binary8、完整掩膜到 ROI、ROI 到候选区域、候选区域到轨迹及计数的可视化。叠加图应明确标示是可视化而非算法中间图。
- 根据运行路径标示软件阈值或 FPGA 实际 S2MM 输出。步骤未执行或中间数据不可用时明确显示原因，不用替代画面冒充实际结果。打包和 DMA 同步以状态描述，不伪造前后图像。
- 控制与快照接口沿用现有预览服务的权限和生命周期，关闭或断开时不干扰主采集、计数和现有预览。仅保留有界最新快照，避免积压。

## 验证

用合成帧和已有测试验证关闭时无调试专用工作、开关生效、快照属于同一帧、来源和不可用状态准确、端点安全及现有预览兼容。检查页面的开启、关闭、断线与窄屏显示；如无法运行板卡，明确说明真实硬件开销和表现尚未验证。
