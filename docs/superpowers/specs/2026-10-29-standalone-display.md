# 脱机灰度显示候选实现

状态：用户已授权按根目录《计划.md》实施；本增量是候选接口，未完成 PR、三人签核或 Route 冻结。

## 阶段边界

G0 固定 PYNQ v3.1 官方源码、板端实际驱动和字体，重建视频 HLS IP。G1 使用独立显示位流验证输出、缓冲与观测；G1.5 验证合成性能。只有这两阶段通过后才将 RLE 并入 G2，随后执行 G2.5/G3/G4。不得用独立显示取代整机验收。

## 有效显示身份

1280×720 灰度画布右侧首行和末行，从 x=640 起各放置 224 个黑白像素，按最高位先行编码：`magic16(0x4d43) + session_uuid128 + frame_id64 + CRC16`。CRC 为 CCITT-FALSE（初值 0xffff、多项式 0x1021），覆盖前 208 位。标识属于显示元数据，不侵入左侧原图。

监测器只观察视频转串行之前实际输出的 RGB、DE 和 VSYNC。完成全部 1280×720 像素、每行长度正确、首尾标识相同且 CRC 有效后，才能在下一 VSYNC 上升沿记录身份。连续重复旧身份只增加重复扫描计数。计数均为像素时钟域 64 位无符号数，模 2^64 回绕；复位清零。

AXI 寄存器：0x00 签名 `0x4d435631`；0x04 写 1 请求快照；0x08 为 busy/valid；0x0c 为完成的快照序号；0x10 新身份、0x18 扫描、0x20 重复、0x28 无效、0x30 截断计数（均为低字在前的 64 位）；0x38 会话 UUID 128 位；0x48 帧号 64 位。快照通过请求/应答 toggle 与稳定邮箱跨域，读取中计数不变化。正常重置必须同时复位两个时钟域；软件必须等到新快照完成后读取。跨域设计仍须仿真、CDC 和实现验证。

G1 诊断增量仍为候选：0x50 的 bit 0～4 依次为非等值灰阶、标识非黑白、首尾不一致、首标识无效、尾标识无效；0x60～0x78 与 0x80～0x98 各保存首、尾 224 位标识，均为低字在前。这些字段与计数器使用同一次原子快照，不读取扫描中的活动寄存器。

G1 板测确认 HWH 的 HP2 参数不自动证明实际 AFI2 位宽已同步。启动必须在 FPGA reset 释放且显示 VDMA halted、无故障时，校验 HWH 的参数和总线都为 32 位，再保留其他控制位同步 AFI2 读控制 bit 0，并严格读回。显示只使用读通路，不改 HP2 写通路或 HP0／HP1。证据见 G1 记录；不因此冻结正式接口。

## 缓冲和软件约束

VDMA 由硬件所有者进程通过 PYNQ 官方帧缓存和调度管理。绘图进程只接触普通共享内存。提交后 CPU 不再访问帧；不能证明停止时进入 FAIL_HOLD 并保留资源。驱动中现有无界等待必须由带单调时限的适配层约束。

Gray8 扫描理论读带宽为 55.296 MB/s。4 个槽、最多 5 个驱动缓存和 1 个 CPU 帧合计 9,216,000 字节（未计分页、分配器、RLE 和临时空间）；G0 暂留 24 MiB CMA 准入预算，最终峰值须实测。三槽 IPC 为普通内存，不能混入 CMA 估算。

原图按 INTER_AREA 缩放 0.9 倍，二值图按 INTER_NEAREST；放入 576×360 区域，左右留 32 像素。坐标采用非负数 `floor(0.9*x+0.5)`，先在原图坐标裁剪，再加区域偏移。上下画面只接受同一个 session/frame 的快照。
