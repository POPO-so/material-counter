# 项目树

本文件列出项目中需要人工维护的主要目录和入口；缓存、构建产物与自动生成文件不列入。

```text
material-counter/
├── .agents/skills/                 项目级 Codex 技能；包含 UI/UX Pro Max、Frontend Design、Web Design Guidelines 和 Vivado 技能
├── data/                           合成输入及实验、板端结果记录
├── docs/                           项目范围、接口、ADR、工作包和验证证据
│   ├── adr/                        架构与方案决策记录
│   ├── verification/               验证报告、交接记录和验收证据
│   └── work-orders/                工作包要求、边界与验收标准
├── fpga/                           FPGA RTL、仿真及实验工程
│   ├── rtl/                        图像前端等 RTL 源码
│   ├── sim/                        RTL 仿真 testbench
│   └── experimental/               隔离的硬件实验实现
├── hw/                             板卡、引脚预算及硬件可行性资料
├── python/                         合成数据工具和处理器端离线参考模型
│   ├── synth/                      确定性合成数据生成与回归
│   └── refmodel/                   PS 区域分析、跟踪与计数参考实现
├── scripts/                        交付完整性核验及工作包自动化脚本
│   └── wo0016/                     受门禁保护的流式计数、相机预览与离线测试
│       ├── dashboard.html          中文蓝白控制看板；真实状态轮询与异步 MJPEG
│       ├── dashboard_state.py      完成帧只读遥测与有界状态事件；不访问硬件
│       ├── mjpeg_preview.py        MJPEG 服务、预览发布与轻量状态接口
│       ├── run_stream_counter.py   受现有许可约束的实板入口及离线 mock 入口
│       └── test_dashboard_*.py     遥测、HTTP 和可选浏览器离线验证
├── skill/                           保留的技能占位目录
├── 文档/                            中文项目维护文档
├── AGENTS.md                       项目级 Agent 协作与范围规则
├── MASTER_PLAN.md                  项目主计划及技术论证
├── PROJECT_INDEX.md                项目上下文导航与最小阅读路径
├── README.md                       项目介绍、当前状态及已有证据摘要
├── .gitattributes                  Git 文件属性配置
└── .gitignore                      临时文件与生成物忽略规则
```
