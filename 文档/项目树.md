# 项目树

说明本项目需要人工维护的主要目录和文件；构建产物、测试缓存及运行生成的数据不在此列。

```text
material-counter/
├── python/synth/                 合成图像、ground truth 与回归测试
├── python/refmodel/              PS 离线算法参考模型
├── fpga/rtl/                     AXI4-Stream 前端、ROI 和形态学 RTL
├── fpga/experimental/            隔离的 FPGA 图像与 DMA 实验链路
├── fpga/sim/                     RTL 仿真测试台与用例
├── fpga/experimental/gray8/      当前 GRAY8_PACKET_V1 AXI-stream 适配、阈值与 S2MM RTL
├── fpga/sim/gray8/               Gray8 AXI-stream 与 wrapper 仿真测试台
├── scripts/wo0015/               共享板端 preflight、DMA helper 与历史工单工具
├── scripts/wo0016/               Gray8 图像流、计数、校准和预览实现
│   ├── web_preview_start.py      可独立测试的板端部署校验、自检与相机预览启动
│   ├── web_preview_stop.py       核对相机和端口所有权后正常停止预览
│   ├── test_web_launcher_*.py    部署配置、真实本机代理及注册表边界测试
│   ├── test_web_preview_workflow.py  板端冷暖启动与自检失败路径的隔离测试
│   ├── resource_monitor.py       可启停的板端资源采样器
│   └── test_resource_monitor.py  资源采样和启停测试
├── scripts/gray8/                唯一 Gray8 包编解码、构建、manifest 与板端运行入口
│   └── README.md                 当前协议、运行方式与验证限制
├── scripts/delivery/             离线回放与交付检查脚本
├── Python脚本/                   双击运行的 Windows Python 工具
│   ├── 启动网页.pyw              双击启动网页、后台连接与板端更新服务
│   ├── 网页部署.json             板卡地址、部署路径、端口与明确确认的产物哈希
│   └── 网页启动说明.md           配置更新、运行目录兼容与验证方法
├── scripts/camera_format_benchmark.py       Linux 相机格式与采集处理基准
├── scripts/test_camera_format_benchmark.py  相机基准的合成数据单元测试
├── scripts/camera_format_benchmark.md       相机基准的板端使用说明
├── docs/                         范围、接口、路线、工单和验证记录
├── 文档/                         中文项目维护文档
├── data/results/                 可追溯的测试、诊断与验收结果
├── hw/                           硬件接口和管脚预算资料
├── README.md                     项目状态、系统结构与运行导航
├── PROJECT_INDEX.md              项目资料和源码的任务导航
├── PLAN.md                       Gray8 唯一运行实现边界与当前状态
├── MASTER_PLAN.md                项目完整方案与长期计划
└── AGENTS.md                     本仓库的协作与变更约定
```
