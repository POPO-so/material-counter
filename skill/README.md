# 可复用技能包

[作品首页](../README.md) · [AMD 指南核对](../docs/competition/CONTEST_REQUIREMENTS.md) · [协作与纠错记录](../docs/competition/AI_COLLABORATION.md)

本目录整理团队开发过程中提炼的方法、脚本和失效边界，供其他 PYNQ/FPGA 项目复用。开发工具安装目录 `.agents/skills/` 不代替本目录的交付内容。

## 已提供的技能

| 技能 | 适用场景 | 方法与边界 |
| --- | --- | --- |
| [PYNQ 离线工件核验](pynq_artifact_audit/README.md) | 在部署或交付前核对 BIT、HWH、PS 源和配置的文件身份 | 使用外部审阅过的 manifest SHA-256，再逐项检查声明文件；不访问板卡，不证明同次构建、依赖闭包或板测通过 |

每项技能包含用途、调用方法、失败条件和验证说明；具体操作入口在对应 `SKILL.md`。该目录不要求安装到 Codex 全局环境，可以直接查看文档并用 Python 运行只读脚本。

## 经验来源

本轮对 JPEG v8 候选的核对发现：包内 18 个源码文件都匹配固定提交，但其中 6 个与所核默认分支不同。由此提炼出“固定清单身份、核对字节、分别报告运行证据”的流程。真实项目案例见[候选清单](../docs/verification/submission-candidates-20261104.json)，合成故障测试仅用于验证脚本拒绝行为。

## 验证与通用性

技能只使用 Python 标准库和文件哈希，不依赖本项目的摄像头、图像尺寸、寄存器地址或物料类别；其他项目可按其已审阅的文件清单使用。这里的通用性限于主机文件核验，不表示已对其他板卡完成 Overlay 加载或硬件运行验证。

2026-11-04 独立重跑的 12 项 CLI 回归全部通过；从真实 JPEG v8 ZIP 解包并转换其已核对清单后，20 个文件核验通过。仅在临时副本中改动 BIT 一个字节后，脚本按预期退出 2 并报告失败；原 ZIP 未变化。摘要见[技能验证记录](../docs/verification/pynq-artifact-audit-20261104.json)。

AMD 指南提到的通用 PYNQ Skill 加分由评审决定，本目录不预先认定得分。完整原始协作会话、最终实物验收和项目授权继续作为独立交付事项。
