# G2.5 HDMI/RLE 并发压力验收

**G2.5 放行。** 本次在同一套 [新 G2 制品](../standalone-20261030-123000-g2-integration/README.md) 上完成固定移动目标、高游程输入、显示开关对照、完整像素验证和 180 s 追加资源复测。各轮正常停止，硬件传输计数与帧数/实收字节一致，无 DMA 错误、稳定期无新增无效/部分扫描。此结论不包含 G3 功能回归或 G4 真正脱机。

板卡 192.168.2.99，boot ID `e48ff153-bd85-4dd6-98f6-438bd51da08d`，BIT SHA-256 `79609f9a60c3e727b5f2f54a8d639a464a098715fb5eb28d294646a9735948e0`，HWH `986de17a030540adc9e892cb6cd7b146ead7b5ddcf0aab2da80a9c0bf5027243`。FCLK0/1/2 = 50/100/142.857143 MHz。每轮一个进程、同一硬件管理者和互斥锁，轮次串行，没有并行加载位流。

## 输入和测量口径

`moving` 是 640×400 中移动的 20×16 灰度目标；`high_runs` 每行 40 个单像素游程、共 16,000 runs，低于 16,384 容量。输入由 `scripts/standalone/pressure.py` 固定生成。它们是有目标/压力合成输入，**没有物料准确率含义**。

`off` 在测量前关闭 VDMA；`scan` 固定一张已由输出端确认的新身份画面并持续 720p60 扫描；`dynamic` 每个结果更新新身份。先确认第一张有效身份，再取基线快照并开始压力统计，启动无标识扫描不混入稳定区间。静态 scan 的有效新帧 FPS 为 0，这是固定画面的预期结果，不冒充动态显示。

显示持续扫描相对关闭显示，本轮移动目标 FPS 变化约 -0.25%，高游程约 +0.15%；这是各一次固定时长对照的实际差异，不是通用 DDR 隔离或统计显著性结论。动态合成降低整体吞吐，计数/显示预算仍须 G3 联合相机实测。

完整像素验证单列：`high-pixels.json` 验证 9 帧高游程，约 2.678 FPS，包含重建/比较开销；G2 `pixel-smoke.json` 另验证 46 帧 moving。这些不混入普通性能轮次。所有本轮 RLE 帧有效；人工物料准确率、真实相机 30 FPS 均未验收。

## 反压、资源与退出

六个计数均在 50 MHz RLE 域，用硬件原子锁存及前后序号复核；输入/输出握手 beat 差值逐轮与实际帧数、回传字节数一致。输入 stall 为非零，输出 stall 在这些板端轮次为 0；RTL/网表中的强制反压场景已经验证输出 stall 计数能增长，不能把板端 0 解释为未测。

高游程最初 35 s 的 CMA 可用量波动较大，因此追加 180 s：**88 次硬件读回的 TX/RX 地址始终为 361234432 / 361103360，两块缓冲各仅分配一次**；RSS 范围 148,612–194,440 KiB，多次明显回落（约60、120、160秒），不是持续单向增长；CMA 随进程普通内存分配/回收波动。这支持本轮有界资源结论，不证明一小时或全部现场输入已验收。总时钟差值 9,001,816,524 超过 32 位范围，64 位读回及 beat 一致性正常。

分核 CPU 的 P50/P95、CMA 区间、延迟、原始每帧时间和硬件快照见 [summary.json](summary.json) 和各轮 JSON；不把 per-core 百分比当整机 CPU。180 s 后 [独立终态](post-long-readback.json) 确认两路 RLE DMA idle/无错误，VDMA halted，pipeline done_seen 且 busy/error 清零，设备 owner/denied 均空，CMA 可用 51,624 KiB / 131,072 KiB。进程退出后的系统/CMA缓存可用量不是每帧 BO 分配数，不能互相代替。
