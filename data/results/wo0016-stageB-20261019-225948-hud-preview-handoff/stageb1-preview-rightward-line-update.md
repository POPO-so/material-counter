# WO-0016 Stage B-1 右移方向计数线修正

## 变更

依据现场确认的物料运动方向“画面向右”，将调光 HUD 从水平 `y=120` 指引改为竖直 `x=160` 指引。ROI 同步改为垂直窄带：`x=136..184`（49 列，半开区间 `[136,185)`），覆盖画面全高。红色阈值叠加、ROI Mean/Peak/FG Pixels/Components 都改在此 ROI 上计算。

下一轮 Stage B-1 启动器也改为使用相同的竖向 ROI。因为现有 WO-0016 计数器接口沿 Y 轴关联，启动器准备了逐帧 Binary8 转置适配器：原图的 `+x` 右移映射为计数器的 `+y`，中心触发坐标映射为 `y=160`。原始帧仍保持 `320×240`；转置只用于 PS 侧计数器输入。

## 当前预览验证

- HUD 服务 PID：`16060`；`/dev/video0` 与 8080 均由此预览进程持有。
- `http://192.168.2.99:8080/` 返回 HTTP 200，页面明确显示竖线 `x=160`、ROI `x=136..184`。
- `/stream.mjpg` 返回 HTTP 200，收到 multipart MJPEG 内容及 JPEG 帧起始标记。
- 最终复核 `CmaFree`: `75,276 KiB`；`boot_id`: `58e6af6c-6660-4d44-b0c5-e18f4a564202`。
- 本地 HUD 与 B-1 启动器通过 Python 静态编译。

## 执行边界

- 本轮只替换并验证 CPU 调光预览；没有启动传送带或光源，没有运行 DMA/正式采样，也没有消费 guard。
- 竖向计数适配器仅在本地下一轮启动器中准备，未上传或运行；因此还没有右移物料的板端计数验证结果。
