# 桌面 GUI 使用说明

## 启动条件

在项目根目录执行 `.\.venv\Scripts\python.exe -m pip install -r scripts/desktop_gui/requirements.txt` 安装桌面依赖，然后在 Windows 资源管理器中双击 `启动GUI.pyw`。启动器优先使用项目根目录的 `.venv` 中的 `pythonw.exe`。GUI 使用 `RLE桌面部署.json` 读取板卡地址、端口、部署路径及固定 SHA-256 期望值。更换板卡或部署版本时，先确认并更新该配置，不要从板卡现有文件反向覆盖期望哈希。

真实用户部署前，需要让当前 Windows 用户的 SSH `known_hosts` 中存在并核验目标板卡的主机密钥。程序加载系统 SSH 主机密钥，并拒绝未知主机密钥；不要改成自动信任未知主机。板卡登录沿用项目默认登录方式。

## 界面和帧处理

界面遵循只显示相机和系统状态的偏好，提供相机预览、采集与停止、系统状态及必要的诊断信息。桌面计数路径使用 `GUI source=pl_rle`：相机原始 640×400 Gray8 帧不缩放，送入 PL 依次执行 ROI、强度偏移、阈值、可选形态学处理并输出游程；PS 使用原生游程区域分析、跟踪和越线计数。PL 不执行完整连通域标记（CCL）。

资源详细模式显示当前固定哈希位流对应的实现报告：LUT 5809/53200（10.92%）、FF 4162/106400（3.91%）、BRAM 2.5/140（1.79%）、LUTRAM 1731/17400（9.95%）、DSP 0。这是静态资源占用，不代表芯片实时忙碌比例。

界面基于 PySide6/Qt Widgets，右上角可选择跟随系统、浅色、深色或高对比度主题；窗口使用系统标题栏和原生窗口管理。界面不使用动画，系统资源及图像处理仍由既有后端负责。

预览通过版本化的 MCF1 v3 帧格式传送图像和状态。预览直接复用同帧相机 MJPEG，在电脑端解码为灰度显示，不缩放尺寸，也不在板端重复 JPEG 编码；二值掩膜以 1 bit 无损传输。计数使用原始解码后的 640×400 Gray8 输入，显示压缩不改变计数输入。没有预览订阅者时，板端不重建整帧掩膜。

当前计数线为竖线 x=320，PL ROI 为全帧，阈值 128、强度偏移 0、形态学关闭；面积与跟踪门限仍采用 RLE 候选参数，需要用真实物料标定。速度中的 cm/s 沿用视野比例估算，不是重新标定的物理测速值。

## 启动、停止和结果

启动时，GUI 通过 SSH 上传独立会话所需文件，按 `RLE桌面部署.json` 核验固定哈希，再执行板端自检及相机启动检查。GUI 只管理自己创建并核对过会话 ID 的任务；不会自动接管其他会话，也不会强制停止无法确认归属的进程。

点击“停止监控”或关闭窗口时，程序会请求板端安全停止，等待采集结束、相机资源释放、标准相机参数恢复及结果写入。若停止状态无法确认，窗口会保持打开并显示原因；不会强制结束板端进程。关闭前请等待界面确认停止。

每次板端会话结果保存在独立会话目录的 `result.json`；启动日志和自检记录也保存在该目录。Windows 本地 GUI 日志位于项目根目录 `.runtime/desktop-gui.log`。

## 网络连接排查

当前网络检查中，Windows 主机 `192.168.2.98` 的有线接口可以 ping 通板卡 `192.168.2.99`；沙箱内 TCP 测试失败，而在正常权限下 `Test-NetConnection` 对 SSH 22 端口成功。沙箱 TCP 测试失败可能来自运行环境的网络限制，不能据此判断板卡离线。

连接失败时，检查有线网卡是否启用、网线和板卡电源、`RLE桌面部署.json` 中的板卡地址，以及板卡 SSH 22 端口是否可达；再确认程序是在允许访问网络的正常桌面权限下运行。不要通过关闭防火墙或降低系统安全设置来排查。

## 验证状态

本轮真实板卡与 Qt 隐藏窗口会话完成 570 帧，无无效帧；368 组显示掩膜的前景数和行列投影与同帧 PL 元数据一致，暂停恢复和安全停止通过。正常窗口板端处理速率约 16.6 FPS、实际展示均值约 14.6 FPS，尚未达到 30 FPS，没有物料真值。详见 [RLE 桌面验证](../data/results/rle-desktop-20261029/README.md)。此前软件桌面与网页的 [历史板测记录](../data/results/desktop-gui-20261028/README.md) 保留，不能作为 RLE 路径结果。
